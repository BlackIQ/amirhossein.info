# I live in the terminal

Open source has been part of my daily life since **2019**.

I write code, maintain repositories, review pull requests, and ship packages because I enjoy it — not because someone asked me to.

Between **2020 and 2022** I was ranked as the **#1 GitHub user in Iran** for three consecutive years. That ranking reflected consistent contribution, not a single viral repository.

Most of my public work lives on GitHub and GitLab: libraries, APIs, platforms, educational repos, and personal experiments. Some projects stay small on purpose. Others grow into full platforms.

I still prefer doing the work over talking about it.
