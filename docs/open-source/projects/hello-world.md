# Hello World

A community-driven repository containing "Hello World" (and small examples) in **150+ programming languages**.

It started as a simple collection and grew into one of the most contributed educational repositories in the Persian developer community.

## Highlights

- **160+ stars** and **135+ forks**
- Hundreds of pull requests and community contributions
- More than 150 languages and frameworks covered
- Used by beginners as a first contribution to open source

## Goal

Make the first step into open source as easy as possible: pick a language, add a Hello World (or a small example), and open a pull request.
