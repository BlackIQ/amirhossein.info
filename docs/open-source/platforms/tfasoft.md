# TFASoft

**TFASoft** is a modern authentication platform that lets developers authenticate users through Telegram.

It provides APIs, official SDKs, a Telegram bot, a mobile app, and supporting tools so developers can add secure authentication with less complexity.

## What it includes

- Core authentication APIs and backend infrastructure
- Official SDKs for multiple languages
- Telegram bot for the authentication flow
- Mobile application
- Dashboard, documentation, status page, and landing site

## Stack

- **Backend / Core:** Authentication services and APIs
- **Clients:** SDKs, Telegram bot, mobile app
- **Docs:** MkDocs
