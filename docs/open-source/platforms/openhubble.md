# OpenHubble

**OpenHubble** is a platform for monitoring, observability, analytics, uptime, and infrastructure tooling. It is designed to run both in the cloud and on-premises.

I am the founder and main maintainer of the project.

## Focus

- Runtime monitoring and metrics collection
- Uptime and status tracking
- Analytics and observability tools
- Infrastructure-oriented services

## Stack

Typical technologies across the platform include:

- **Backend:** FastAPI, PostgreSQL
- **Agents & collectors:** Python
- **Deployment:** Docker, cloud-native setups
